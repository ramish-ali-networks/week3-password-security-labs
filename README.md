# Week 3 – Password Security & Cracking Labs 🔐

## Overview

This repository documents my Week 3 practical cybersecurity training activities, focused on password security and password recovery techniques.

During these exercises, I explored how password hashes are extracted and how password-cracking tools test possible passwords in an authorized lab environment.

## Practical Labs

### Lab 01 – Password Cracking with John the Ripper (JTR)

**Tools Used:**
- John the Ripper
- Johnny GUI
- PDF Hash Extraction Tool

**What I Practiced:**
- Extracting password hashes from protected PDF files.
- Saving extracted hashes in a text file.
- Configuring Johnny with John the Ripper.
- Performing a password-recovery test.

### Lab 02 – Password Cracking with Networkwalks Tools

**Tools Used:**
- Networkwalks Hash Calculator
- Networkwalks Password Cracker
- Web Browser

**What I Practiced:**
- Uploading an encrypted PDF for hash extraction.
- Understanding PDF password hash formats.
- Using a dictionary attack to test password candidates.
- Recovering the sample PDF password successfully.

## Key Learning Outcomes

- Understanding password hashes and their role in file security.
- Learning the difference between hashing and encryption.
- Understanding dictionary-based password attacks.
- Exploring practical password auditing tools.
- Recognizing the importance of strong and unique passwords.

## Ethical Use

These exercises were performed for educational purposes in an authorized training environment using provided sample files.

Password-cracking techniques should only be used on files and systems for which you have explicit permission.
